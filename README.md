# Bradley Joandrey - Portfolio Website
A modern, responsive portfolio website showcasing my skills, experience, projects, and certifications. Built with React and Vite for optimal performance and user experience.

## 🚀 Live Demo
[View Portfolio](https://bradleyjoandrey.github.io/bradleyjoandrey-portfolio)

## 📋 Features
- **Responsive Design**: Optimized for all device sizes
- **Modern UI/UX**: Clean and professional interface built with Tailwind CSS
- **Smooth Animations**: Enhanced user experience with Framer Motion
- **Interactive Navigation**: Smooth scrolling between sections
- **Portfolio Sections**:
  - Hero section with introduction
  - About me
  - Skills
  - Work experience
  - Featured projects
  - Certifications

## 🛠️ Technologies Used
- **Frontend**: React 19.1.0, JavaScript (ES6+)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (with Autoprefixer)
- **Animations**: Framer Motion (Motion)
- **Icons**: React Icons
- **Navigation**: React Scroll
- **Deployment**: GitHub Pages
- **Code Quality**: ESLint with React-specific rules

## 🚀 Getting Started

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation
1. Clone the repository:
git clone https://github.com/bradleyjoandrey/bradleyjoandrey-portfolio.git

2. Navigate to the project directory:
cd bradleyjoandrey-portfolio

3. Install dependencies:
npm install

4. Start the development server:
npm run dev

5. Open your browser and visit `http://localhost:5173`

## 📦 Available Scripts
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality checks
- `npm run deploy` - Deploy to GitHub Pages

## 🎨 Customization

### Styling
The project uses Tailwind CSS for styling. You can customize the design by:
- Modifying `tailwind.config.js` for theme customization
- Editing component styles in individual JSX files
- Adding custom CSS classes as needed

### Content
To update portfolio content:
1. Edit component files in the respective section folders
2. Update personal information in the hero and about sections
3. Add/remove projects, skills, and certifications as needed
